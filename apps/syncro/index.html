Standalone / HPC

Run the same pipeline with Node.js 22+ on a workstation or compute node. Synthesis and brain extraction use native ONNX Runtime; registration uses the same ANTs WebAssembly build.

Download npm package · 0.1.0
ONNXRUNTIME_NODE_INSTALL=skip npm install -g \
  --prefix "$HOME/.local" ./neurodesk-syncro-0.1.0.tgz
export PATH="$HOME/.local/bin:$PATH"
syncro input.nii.gz results --threads 4
syncro download-models --cache-dir /shared/syncro
syncro input.nii.gz results \
  --cache-dir /shared/syncro --offline

On SLURM, request 4 CPUs and 32 GB RAM initially. Set --threads "$SLURM_CPUS_PER_TASK". Use --lesion lesion.nii.gz for binary lesions, or --labels atlas.nii.gz for categorical labels. --resume reuses verified synthesis and extraction checkpoints after interruption.
