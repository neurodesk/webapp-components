Technical log

Deface

Remove facial features from brain MRI for anonymization entirely in your browser. No imaging data is sent to a server.

The allineate methods use niimath to register an MNI template and remove facial voxels. MindGrab uses local WebGPU brain extraction. Visualization uses NiiVue and DICOM import uses dcm2niix.

This BSD-2-Clause app fails closed if processing cannot complete. Always review the result before sharing it.

Privacy

Deface processes scans locally in your browser. It does not upload your source image or defaced result. Always inspect the output before sharing it.

MindGrab needs WebGPU

MindGrab needs WebGPU with shader-f16 support. Use an allineate method if this browser does not provide it.
