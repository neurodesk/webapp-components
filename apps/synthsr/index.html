SynthSR

A browser implementation of SynthSR, developed by Iglesias, Billot and colleagues. Uses the pretrained v2 model and reproduces its 1 mm resampling, normalization, flip averaging and sharpening workflow.

Reference implementation · Iglesias et al., NeuroImage (2021)

Full-volume mode follows the reference method. Tiled mode reduces memory use but changes context and may introduce boundary differences. Outputs are synthetic images for research; they are not acquired T1 scans.

Neural inference uses ONNX Runtime Web 1.29.0; visualization uses NiiVue 1.0 RC. Source and model attribution: Apache-2.0.

Run SynthSR on your computer or HPC

The standalone npm package uses the same processing pipeline and model as this app, with native ONNX Runtime. It runs from a terminal without a browser or display server. Install Node.js 22 or newer first.

Download standalone npm package · v0.1.0

Install and run

Run these commands in the folder containing the downloaded package. This CPU installation needs no administrator privileges.

ONNXRUNTIME_NODE_INSTALL=skip npm install --global \
  --prefix "$HOME/.local" ./neurodesk-synthsr-0.1.0.tgz
export PATH="$HOME/.local/bin:$PATH"
synthsr input.nii.gz output_synthsr.nii.gz --threads 8

The first run downloads the public model and verifies its checksum. Results include a synthetic NIfTI image and a JSON file with settings and timings. Existing results are protected unless you pass --force.

Prepare an offline compute node

Install the package and fetch the model on a networked node with the same operating system and architecture. Keep both on a filesystem accessible to compute nodes. Choose a shared cache path:

synthsr download-model --cache-dir /shared/synthsr-models
synthsr input.nii.gz output_synthsr.nii.gz \
  --cache-dir /shared/synthsr-models --offline --threads 8

Slurm job example

Adapt the paths and resource request for your cluster, then save this as synthsr.sbatch and submit it with sbatch synthsr.sbatch. Load your cluster's Node.js module if required.

#!/bin/bash
#SBATCH --job-name=synthsr
#SBATCH --cpus-per-task=8
#SBATCH --mem=32G
#SBATCH --time=00:30:00
set -euo pipefail
export PATH="$HOME/.local/bin:$PATH"
synthsr /shared/input.nii.gz /shared/output_synthsr.nii.gz \
  --cache-dir /shared/synthsr-models --offline \
  --threads "$SLURM_CPUS_PER_TASK"

Full-volume mode, flip averaging and sharpening are enabled by default. Use --ct for CT in Hounsfield units, or --help for all options. --tiled reduces memory but changes spatial context and may introduce seams.

CPU is the tested standalone backend. --device cuda requires a CUDA-enabled ONNX Runtime installation and matching CUDA/cuDNN libraries; the CPU-only installation above skips those libraries. CUDA fails explicitly if unavailable.
