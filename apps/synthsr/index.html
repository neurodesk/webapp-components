SynthSR

A browser implementation of SynthSR, developed by Iglesias, Billot and colleagues. Uses the pretrained v2 model and reproduces its 1 mm resampling, normalization, flip averaging and sharpening workflow.

Reference implementation · Iglesias et al., NeuroImage (2021)

Full-volume mode follows the reference method. Tiled mode reduces memory use but changes context and may introduce boundary differences. Outputs are synthetic images for research; they are not acquired T1 scans.

CPU inference uses ONNX Runtime Web 1.29.0; GPU inference uses optimized FP32 kernels; visualization uses NiiVue 1.0 RC. Source and model attribution: Apache-2.0.

Run SynthSR in a terminal

Linux x64 · paste these commands to download Node.js and SynthSR, install locally, and run on CPU. No administrator access needed.

curl -fLO https://nodejs.org/dist/v22.22.0/node-v22.22.0-linux-x64.tar.xz
tar -xf node-v22.22.0-linux-x64.tar.xz
export PATH="$PWD/node-v22.22.0-linux-x64/bin:$PATH"
curl -fLO https://webapps.neurodesk.org/synthsr/downloads/neurodesk-synthsr-0.1.0.tgz
ONNXRUNTIME_NODE_INSTALL=skip npm install --prefix ./synthsr-cli ./neurodesk-synthsr-0.1.0.tgz
./synthsr-cli/node_modules/.bin/synthsr input.nii.gz output_synthsr.nii.gz --threads 8

Replace input.nii.gz with your scan. The first run downloads and verifies the model. Add --ct for CT. Output includes the synthetic image and a JSON report.

Already have Node.js 22+? Skip the first three lines. Download the package · use --help for options.
