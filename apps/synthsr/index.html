Technical log

SynthSR

A browser implementation of SynthSR, developed by Iglesias, Billot and colleagues. It uses the pretrained v2 model and reproduces its 1 mm resampling, normalization, flip averaging and sharpening workflow.

Full-volume mode follows the reference method. Tiled mode reduces memory use but changes context and may introduce boundary differences. Outputs are synthetic images for research; they are not acquired T1 scans.

How to cite SynthSR

Primary reference

Iglesias JE, Billot B, Balbastre Y, et al. Joint super-resolution and synthesis of 1 mm isotropic MP-RAGE volumes from clinical MRI exams with scans of different orientation, resolution and contrast. NeuroImage. 2021;237:118206. PMID 34048902. DOI: 10.1016/j.neuroimage.2021.118206.

Please also cite NiiVue and ONNX Runtime when they are material to your analysis.

Privacy

SynthSR processes scans locally in your browser. It does not upload your input image, model selection, synthetic output, or processing report.

Run SynthSR in a terminal

Linux x64 · paste these commands to download Node.js and SynthSR, install locally, and run on CPU. No administrator access needed.

curl -fLO https://nodejs.org/dist/v22.22.0/node-v22.22.0-linux-x64.tar.xz
tar -xf node-v22.22.0-linux-x64.tar.xz
export PATH="$PWD/node-v22.22.0-linux-x64/bin:$PATH"
curl -fLO https://webapps.neurodesk.org/synthsr/downloads/neurodesk-synthsr-0.2.20260909.tgz
ONNXRUNTIME_NODE_INSTALL=skip npm install --prefix ./synthsr-cli ./neurodesk-synthsr-0.2.20260909.tgz
./synthsr-cli/node_modules/.bin/synthsr input.nii.gz output_synthsr.nii.gz --threads 8

Replace input.nii.gz with your scan. The first run downloads and verifies the model. Add --ct for CT.
