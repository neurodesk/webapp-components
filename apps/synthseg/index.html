Technical log

SynthSeg

A browser implementation of SynthSeg 2.0, developed by Billot, Greve, Iglesias and colleagues. It uses the pretrained FreeSurfer 8.1.0 model and reproduces its 1 mm resampling, normalization, flip averaging and topological label workflow.

Default mode follows the reference method. Fast mode skips flip averaging and topological correction, so labels may differ slightly. Segmentation runs on WebGPU; a browser without WebGPU cannot run this app.

How to cite SynthSeg

Primary reference

Billot B, Greve DN, Puonti O, et al. SynthSeg: Segmentation of brain MRI scans of any contrast and resolution without retraining. Medical Image Analysis. 2023;86:102789. doi:10.1016/j.media.2023.102789.

Please also cite NiiVue when it is material to your analysis.

Privacy

SynthSeg processes scans locally in your browser. It does not upload your input image, labels, or processing report.

Only two files are downloaded from Hugging Face: the pretrained model, and the example image if you choose one.

Run SynthSeg in a terminal

A native command-line SynthSeg (ONNX Runtime on CPU, Metal on Apple silicon) lives in exes/synthseg of the webapps repository. Build and run it with:

git clone https://github.com/neurodesk/webapps
make -C webapps/exes/synthseg build
./webapps/exes/synthseg/target/release/synthseg input.nii.gz output_synthseg.nii.gz

Add --fast for the single-pass mode and --ct for CT input. Prebuilt downloads are not published yet.
